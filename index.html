Selected projects
QUANTIZATION · INFERENCE

Uncertainty-Aware Inference for Quantized LLMs

Collaboration with IBM Research. Benchmarked Mistral-7B under GPTQ, AWQ, and NF4 quantization, profiling GPU kernels with Nsight Compute and roofline analysis. Showed kernel choice, not bit-width, drives speed: GPTQ INT4 (Marlin) reached 1.78× FP16 throughput in vLLM, while AWQ INT4 at the same precision ran 4.5× slower. Quantization also cut average calibration error (0.229 → 0.067) but raised worst-case error (0.33 → 0.94) on a medical QA benchmark.

REAL-TIME ML · XGBOOST

Real-Time De-escalation Engine for Conversational LLMs

Closed-loop system that detects rising user frustration and adapts an LLM chatbot’s tone before it escalates. GoEmotions BERT with VAD projection feeds a rolling-window XGBoost model that predicts escalation two turns ahead (AUC 0.79 on 50K conversations); SHAP drivers become directives for a quantized Mistral-7B, and a paired A/B test showed a significant +0.27 valence shift (p < 0.05).

3D VISION · GAUSSIAN SPLATTING

Training-Free Segmentation of 3D Gaussian Splatting Scenes

Training-free pipeline that segments objects in a pretrained 3D Gaussian Splatting scene from a text prompt alone. GroundingDINO and SAM2 masks from 8 orbital views are lifted onto individual Gaussians by opacity weighting, enabling 3D-consistent recoloring, removal, and natural-language edits (e.g., “change the flowers to green”) on Mip-NeRF 360 scenes without retraining.

COMPUTER VISION · MULTIMODAL FUSION

Hybrid SIFT + ResNet50 Fusion for Yoga Pose Recognition

Co-authored research fusing MediaPipe-guided SIFT and edge descriptors with ResNet50 features through a learned feature-wise gate and late fusion.
